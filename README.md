# Allumette

### whats the game ?
their are 12 sticks. each player can take 1, 2 or 3 sticks and the player that take the last one loose the game.
each player play turn by turn.
a player can be an Ai, Random Ai or a Human Player

### how to install the app :

1. clone git repository 
2. create a Virtual Environment 
3. install the requirements on your Virtual Environment
4. start game by launching the file main.py

### commande to install the game :

- git clone https://github.com/NwaSet/AIProject
- python -m venv env
- env\Scripts\activate (only for windows)
- source env/bin/activate (only MacOs or Unix)
- pip install -r requirements.txt
- python main.py
